## 🎯 Category Overview

Text analysis prompts leverage AI's natural language understanding to:
- **Understand sentiment** and emotional undertones
- **Summarize** lengthy content efficiently
- **Extract** key themes, entities, and insights
- **Compare** multiple documents for patterns

---

## 🔧 Techniques Used

- **Chain-of-Thought**: Step-by-step analysis reasoning
- **Structured Output**: Tables, JSON, formatted reports
- **Role Assignment**: Expert analyst personas
- **Few-Shot Examples**: Consistent output formatting

---

## 💡 Pro Tips

1. **Provide full context** - Include the complete text when possible
2. **Specify output format** - Tables, bullets, or structured reports
3. **Define analysis scope** - What aspects matter most?
4. **Use Claude for long documents** - Leverage 200K context window
